# Skill frame

Every skill under `skills/` follows this file. The skill itself is one line plus the procedure. Do not paste this page back into the skill.

## Read

Before a plan or a draft, read the owner's brand and audience files when the skill runs inside a Dreamstate setup (`brand/AGENTS.md`, then `audience/AGENTS.md`). A file marked `Status: blank`, or a missing file, means ask. Do not guess a color, a voice line, or a claim. In this public repo those files are not included.

## Consent

Nothing posts, comments, sends a message, uploads, schedules, spends, commits, pushes, or deletes without the owner's yes on that exact item. A draft is not a yes.

## Facts

Do not invent a metric, a customer, a quote, a face, or a feature. Unknown stays unknown, and a missing number is `null`.

## Writing

Drafted copy uses no em dash. Records and docs in this repo also use no en dash and no double hyphen. Use a period, a comma, or and. `npm run validate` checks this.

## Sources

Link to public posts. Quote at most 18 words. Never store full post text, transcripts, or video files from another company.
